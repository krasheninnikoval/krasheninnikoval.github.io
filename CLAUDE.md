# Правила проекта

## Типографика

- **Никакого капслока.** Текст полностью заглавными буквами не используется нигде: ни в заголовках разделов, ни в подписях, ни в кнопках, ни в тэгах. Заглавная буква — только там, где этого требует язык: начало предложения, имена собственные, аббревиатуры (B2B, PDF, HR).
- Широкий межбуквенный интервал (`tracking`) применяем только к крупным заголовкам в минус, для разрядки строчного текста — не используем.
- Шрифт всего сайта — Golos Text.

## Дизайн

- Тема только светлая, тёмной нет намеренно.
- Палитра нейтральная, акцент делается контрастом, а не цветом.
- Адаптив обязателен, нижняя граница проверки — 360px.
