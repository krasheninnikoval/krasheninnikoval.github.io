# Сайт-портфолио

Next.js 16 + TypeScript + Tailwind 4. Светлая тема, статическая генерация, деплой на Vercel.

## Где лежит контент

| Файл | Что внутри |
|---|---|
| `src/content/profile.ts` | ФИО, должность, текст «обо мне», фото, контакты, ссылка на резюме |
| `src/content/projects.ts` | Список проектов: название, описание, тэги, результаты, привязка кейсов |
| `src/content/cases/*.ts` | Кейсы: шапка, метрики и блоки тела |
| `src/content/types.ts` | Схема данных — что обязательно, что нет |
| `src/content/site.ts` | Адрес сайта и описание для поисковиков |
| `public/images/` | Картинки |
| `public/resume.pdf` | Файл резюме |

## Команды

```bash
npm run dev    # локальный просмотр на http://localhost:3000
npm run build  # сборка (падает, если в контенте ошибка)
npm run lint   # проверка кода
```
